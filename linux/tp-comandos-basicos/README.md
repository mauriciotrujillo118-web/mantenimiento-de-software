## 1. Gestion de Archivos y Directorios

## 2. Monitoreo de Procesos
![El comando ps muestra los procesos de la terminal actual en ese momento, mientras que top muestra los procesos del sistema y actualiza la informacion en tiempo real. El comando kill pid sirve para solicitar el cierre de un proceso cuando un programa queda colgado, reemplazando pid por el numero que identifica a ese proceso.](./assets/02_procesos_top.png)
## 3. Informacion del Sistema
![El comando uname -a muestra informacion del nucleo del sistema, como su nombre, version y fecha de compilacion, ademas de la arquitectura del equipo. El comando free muestra la memoria RAM total, usada y libre, junto con el uso de la memoria de intercambio (swap).](./assets/03_info_sistema.png)
## 4. Red y Espacio en Disco
